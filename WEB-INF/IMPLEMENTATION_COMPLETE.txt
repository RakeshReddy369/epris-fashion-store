## 🚀 How to Use

### For Testing:
1. Open any page with interactive-features.js
2. Features auto-initialize on page load
3. Try each feature:
   - Add item to cart → See toast + counter update
   - Click search → Search for products
   - View product → Hover to zoom image
   - Click product card → See quick view modal
   - Scroll page → See smooth animations

### For Development:
```html
<!-- Add to any page -->
<script src="interactive-features.js" defer></script>

<!-- Then use functions -->
<button onclick="showToast('Hello!', 'success')">Test</button>
```
